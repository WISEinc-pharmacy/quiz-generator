1. 概要

調剤薬局スタッフ向け効果試験（理解度テスト）の問題作成・配布・採点を一気通貫で行うWebツール。

全体フロー

  1. 問題プール作成 — PDF/CSV/Excel読み込み → AI問題生成 or 既存問題インポート
  2. 問題集作成 — テーマ別出題数指定 → シャッフル → 配布URLコピー
  3. スタッフが回答 — quiz.html にGoogleログイン → 回答送信（GAS経由でDrive保存）
  4. 一括採点 — 管理者が採点ボタン → 正解キーと自動照合 → 合否判定

テーマ4本柱

  1. 調剤報酬（改定通知PDF）
  2. 会社理念・方針（社内資料）
  3. アカデミック（学術教材）
  4. 経営・事業戦略

3. 問題プール

3.1 テーマ選択

デフォルトテーマ: 調剤報酬 / 会社理念・方針 / アカデミック / 在宅医療 / 経営・事業戦略 / 危機管理

カスタムテーマも自由入力で追加可能。

3.2 ファイル読み込み

対応形式説明
PDFpdf.jsでテキスト抽出。ページ範囲指定可。
TXT / CSVテキストとして読み込み
Excel（.xlsx/.xls）SheetJS（CDN）で読み込み
Google Sheets共有URLから直接読み込み（閲覧権限必須）

複数ファイル同時選択可。テキストは結合されて表示。

3.3 AI問題生成

ボタン: 「AIで問題を生成」 → GASプロキシ経由でClaude API呼び出し

パラメータ選択肢
問題数5 / 10 / 15 / 20 / 30問
選択肢数3 / 4 / 5 / 6択
難易度基礎 / 標準 / 応用
対象薬剤師 / 一般職 / 全職種
カスタム指示自由入力

費用目安: 10問あたり約$0.01〜0.02（Anthropic API）

3.4 既存問題インポート

ボタン: 「既存問題をそのままインポート」（API不使用・無料）

スプレッドシートからコピペした問題を自動パース。タブ区切り・パイプ区切り・CSV対応。

3.5 プール管理

操作説明
展開/折畳みテーマごとにクリックで問題一覧を展開
個別編集問題文・選択肢・正解番号・解説をモーダルで修正
個別削除問題単位で削除
テーマ全削除テーマごと全問削除
Driveに保存テーマ選択 → 備考（8字以内） → Drive保存
Driveから読み込むファイル一覧選択 → テーマ選択 → 上書き or マージ
すべての問題をPDF全テーマのレビュー用PDF出力（修正チェック欄付き）
テーマ別レビューPDF各テーマカードから個別PDF出力

3.6 Drive保存の仕様

  • ファイル名: YYYYMMDD_テーマ1_テーマ2_NNq_備考.json
  • 保存先: Drive固定フォルダ（ID: 1JFZ3tA9l9JKUzkU-MPD7kbDjakOljac4）
  • 備考: 8文字以内。ファイル名とJSON内に保存。読み込み一覧でバッジ表示。
  • テーマ選択: チェックボックスで保存対象を選択。チェックしたテーマは1ファイルにまとめて保存。
  • 読み込みモード: 上書き（既存プール消去） or マージ（既存に追加）

4. 問題集作成

4.1 テーマ別出題数

プールの各テーマから何問出すか数値入力。問題は全体でシャッフル。

職能テーマ指定: チップで「職能」に切り替え可。デフォルト職能: アカデミック。

4.2 問題集名

作成時にダイアログで名前入力。

  • デフォルト: 効果試験_YYYYMMDD_HHmm
  • quizId: 入力名_タイムスタンプ13桁
  • 採点タブでは名前部分のみ大きく表示、IDは小さく併記

4.3 配布

配布URL: https://wiseinc-pharmacy.github.io/quiz-generator/quiz.html?id={quizId}

「配布URLをコピー」ボタンでクリップボードにコピー。スタッフにメール等で送付。

4.4 問題集作成時の処理

  1. テーマごとにシャッフル → 全体もシャッフル
  2. localStorageに saved_quizzes[quizId] 保存
  3. GASに正解キー送信（Drive answer-keys フォルダにJSON保存）

5. 採点

5.1 問題集一覧

GAS APIから取得（Drive answer-keys フォルダ）。作成日時降順表示。

ステータス: 受付中 / 締切済

5.2 一括採点

「一括採点」ボタン → GAS action=gradeAll 呼び出し → 全回答を正解キーと照合

結果テーブル: 氏名 / メール / 提出日時 / 正解数 / 正答率 / 共通 / 職能 / 判定 / 不合格理由

5.3 問題集の管理

操作効果スタッフ側への影響
締切closedフラグをON。正解データは残る。quiz.htmlに「締め切られています」と表示。回答不可。
再開closedフラグをOFF。再び回答可能になる。
削除正解キーをDriveゴミ箱へ移動。回答データは残る。quiz.htmlに「Quiz not found」と表示。

※ Driveゴミ箱は30日間保持。その間は復元可能。

5.4 採点結果の出力

  • 結果をコピー: TSV形式でクリップボードへ（スプシ貼付用）
  • 採点結果PDF出力: 結果テーブルをPDF印刷
  • 採点用紙印刷（設定メニュー内）: 正解一覧 + 回答記入欄 + 集計欄（手採点用）

7. 配布ページ（quiz.html）

認証フロー

  1. ページ読み込み → Firebase Auth初期化
  2. Googleログイン（社内アカウント限定）
  3. ログイン済みユーザーのメールアドレスを表示

回答フロー

  1. GAS action=getQuizQuestions で問題取得（正解・解説は含まない）
  2. 氏名・所属店舗を入力（必須）
  3. 各問題の選択肢をクリックして回答
  4. 「送信」→ 確認ダイアログ（未回答数を警告）→ GASへ送信

制約

  • 1人1回: 同一quizId + emailで重複チェック（二重送信防止）
  • 締切チェック: closedフラグONの問題集は回答不可
  • ログイン必須: Firebase Auth未認証では回答できない

10. 合格基準・採点ロジック

判定条件（すべて満たす必要あり）

条件基準
全体正答率65%以上
共通問題正答率50%以上（該当する場合）
職能問題正答率50%以上（該当する場合）

配置例

対象構成合格ライン
薬剤師共通20問 + アカデミック(職能)20問 = 40問全体26問 + 共通10問 + 職能10問
一般職共通40問 = 40問全体26問 + 共通20問

不合格理由（表示テキスト）

  • Overall below 65% — 全体正答率が65%未満
  • Common below 50% (x/y) — 共通が50%未満
  • Role below 50% (x/y) — 職能が50%未満

11. セキュリティ

認証

対象方式用途
quiz.html（スタッフ）Firebase Auth（Google）なりすまし防止 + 重複回答チェック
GAS generateQuizQUIZ_API_TOKENAPI不正利用防止
GAS submitAnswerFirebase IDトークン検証メールアドレス確認

APIキー管理

キー保管場所用途
ANTHROPIC_API_KEYGAS Script PropertiesClaude API呼び出し
FIREBASE_API_KEYGAS Script PropertiesIDトークン検証
QUIZ_API_TOKENGAS Script PropertiesgenerateQuiz認可

データ保護

  • quiz.htmlには正解・解説を送信しない（問題と選択肢のみ）
  • APIキーはブラウザに露出しない（GASプロキシ経由）
  • gas/ディレクトリは.gitignoreで除外
